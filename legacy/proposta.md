# Proposta de Novo Portfólio: João Pedro Veríssimo Gonçalves

## 1. Análise do Portfólio Atual

O portfólio atual (versão 2024) apresenta uma base sólida com projetos variados que demonstram competências tanto em front-end quanto em back-end. No entanto, existem áreas de oportunidade para elevar a percepção profissional e destacar diferenciais competitivos.

### Pontos Fortes:
- **Diversidade de Projetos:** Engloba jogos educativos, sistemas de gestão (pizzaria), plataformas sociais (Rank.it) e projetos institucionais (Museu IFSP).
- **Progressão Histórica:** Mostra a evolução do profissional desde 2021 até o presente.
- **Clareza de Responsabilidades:** Explica o papel desempenhado em projetos de grupo (ex: Rank.it).

### Áreas de Melhoria:
- **Design Visual:** O layout atual é funcional, mas carece de um toque moderno (micro-interações, tipografia refinada e hierarquia visual mais clara).
- **Destaque de Autoridade:** João Pedro possui 16 artigos técnicos no Dev.to sobre tópicos complexos (POO, Redes, Data Science). Isso não é mencionado no portfólio atual e é um diferencial enorme.
- **Seção de Habilidades:** As tecnologias são mencionadas apenas dentro das descrições dos projetos, dificultando uma leitura rápida das "stacks" dominadas.
- **Experiência do Usuário (UX):** A navegação é puramente vertical e linear. O uso de cards mais dinâmicos e seções bem definidas melhoraria a retenção do visitante.

## 2. Proposta de Alterações

A proposta visa transformar o portfólio de uma "lista de projetos" para uma "plataforma de autoridade técnica".

### A. Estrutura de Conteúdo
1.  **Hero Section (Boas-vindas):** 
    - Impacto visual imediato com uma frase que resuma sua paixão: *"Desenvolvedor apaixonado por transformar lógica e ciência em soluções digitais."*
    - Call-to-action (CTA) claro para "Ver Projetos" ou "Ler Artigos".
2.  **Sobre Mim (Narrativa):**
    - Expandir a bio para mencionar o curso de ADS no IFSP e sua dedicação em ensinar (mencionar a monitoria/artigos).
3.  **Stack Tecnológica:**
    - Seção visual com ícones das tecnologias: JavaScript (Node.js/React), Python, C++, MySQL, etc.
4.  **Showcase de Projetos (Grid):**
    - Cards com tags de tecnologia (ex: #Python #Flask #React).
    - Link direto para o "Live Demo" e "Repositório".
5.  **Seção de Artigos (Diferencial):**
    - Um feed ou seleção manual dos melhores artigos do Dev.to (ex: "Entendendo Polimorfismo", "Softmax e Cross-Entropy"). Isso demonstra profundidade de conhecimento.
6.  **Contato Profissional:**
    - Formulário simples ou botões de contato destacados, incluindo o e-mail de forma mais elegante.

### B. Identidade Visual e UI/UX
- **Tema:** Implementar um "Dark Mode" por padrão ou como opção, remetendo a ambientes de desenvolvimento.
- **Tipografia:** Uso de fontes modernas como *Inter* para o corpo do texto e *JetBrains Mono* para elementos técnicos ou títulos pequenos.
- **Animações:** Transições suaves de entrada (fade-in) e hover effects nos cards de projetos.
- **Responsividade:** Design mobile-first rigoroso.

### C. Sugestão de Tech Stack (Implementação)
Para garantir performance, SEO e facilidade de manutenção:
- **Framework:** Next.js (React) ou Astro (excelente para portfólios focados em conteúdo).
- **Estilização:** Tailwind CSS (para um design moderno e rápido de iterar) ou CSS Modules.
- **Hospedagem:** Vercel ou GitHub Pages.
